# Security Sanitizer Suite

A collection of lightweight local security and privacy tools built for everyday development workflows.

## Tools

| Tool | Description | Stack |
| :--- | :--- | :--- |
| **[VS Code Path Sanitizer](./vscode-path-sanitizer/)** | Masks Windows usernames (`admin` → `user`) in `C:\` paths on `Ctrl+C` and restores them on `Ctrl+V` across VS Code's editor and integrated terminal. | Node.js / VS Code API |
